# ICIR Technical Reports Archive

**Institute for Cognitive Intelligence Research (ICIR)**  
*Official Working Papers and Reproducible Technical Reports*

---

## Technical Report Standards

Every technical report deposited in this archive must provide:
1. **Abstract & Formal Setting:** Self-contained problem description with complete mathematical notation.
2. **Reproducibility Guarantee:** A direct reference to the git commit and experiment IDs in `experiments/register.md` that substantiate all empirical figures and tables.
3. **Open Access:** Distributed under the Creative Commons Attribution-ShareAlike 4.0 International license.

---

## Directory Conventions

Technical reports are placed in subdirectories formatted as:
`publications/technical-reports/TR-YYYY-NNN-slug/` containing:
- `paper.md` (or LaTeX source directory)
- `figures/` (vector diagrams and plots)
- `biblio.bib` (complete bibliographic citations)
